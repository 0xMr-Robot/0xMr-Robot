## 👨‍💻 A little about me

I'm a cybersecurity analyst and malware researcher from Egypt, with a Computer Science background from **Mansoura University**. My work sits at the intersection of **malware analysis, reverse engineering, incident response, threat hunting, and security education**.

Professionally, I investigate security incidents, analyze suspicious code and behavior, and translate technical findings into useful detection and response guidance. Outside of work, I enjoy building security projects, authoring CTF challenges, and teaching through practical labs.

- 🔐 **Currently:** Cyber Security Analyst at **SMART Technology Solutions**.
- 🎓 **Teaching:** Malware Analysis Instructor at **Netriders** and Cyber Security Instructor at **Networkat**.
- 🚀 **Building:** **Vanguard**, a unified, AI-assisted cybersecurity analysis platform.
- 🧩 **Competing:** Reverse engineering and digital forensics challenges with **0xFUN**.
- 📚 **Sharing:** Hands-on tutorials and research through **BlacKSilence12** and technical writing.

> **My approach:** Understand the behavior. Follow the evidence. Explain the finding. Improve the defense.
